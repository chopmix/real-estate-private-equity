# Real Estate Private Equity for Claude

For acquisitions, asset management and capital teams at real estate investment firms. Screen a deal in minutes, underwrite it in your own model, run diligence, write the IC memo and keep every asset on plan.

Created by Chi Hathiramani, CH Consulting. https://chiraghathiramani.com

## What is in this repository

| Folder | Contents |
|--------|----------|
| `plugin/` | The Claude plugin: skills, commands, playbooks and model standards. This is what gets installed. See `plugin/README.md` |
| `tools/` | Development tools that are not part of the plugin: a reference quick screening model, a workbook auditor and tests |
