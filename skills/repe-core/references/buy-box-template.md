## Screening weights

Points added to or subtracted from a starting score of 5. Adjust to the firm's priorities.

| Factor | Points |
|--------|--------|
| Priced below market or replacement cost | +3 |
| Priced at market | 0 |
| Priced above market | -3 |
| Clear path to add value | +2 |
| Fits target market and property type | +1 |
| NOI and cap rate disclosed and supportable | +1 |
| Key data missing | -1 |
| Outside a hard limit in this buy box | Pass |
